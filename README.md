# Higher Rank — Ascent (concept site)

A separate design exploration for Higher Rank. It does not replace any approved Higher Rank work.

- `index.html` is the current version. It is one self-contained file: open it in a browser.
- `versions/` holds every earlier save point, so nothing is lost:
  - `v1-rank-order.html` — typographic ranked-list concept (not approved)
  - `v2-ascent-terraces-vermilion.html` — first WebGL world
  - `v3-ascent-terraces-aurora.html` — new palette and richer sky
  - `v4-ascent-dunes.html` — moonlit dunes, full resolution, real lighting (same as `index.html`)

## Status
- Content is placeholder where marked. The contact form is not connected.
- Tested in a headless desktop browser only. Not yet verified on a real graphics card or phone.

## Editing
The file is labeled by section. CSS: S0 tokens, S1 HUD, S2 panels, S3 mobile. The shader is the script with id `fs`. JS: J0 setup, J1 HUD, J2 camera, J3 WebGL, J4 frame loop, J5 sound, J6 form.
